Cucumber - BDD

1. npm init -y
2. npm install cypress --save-dev
3. npm install --save-dev @badeball/cypress-cucumber-preprocessor
   - Cypress ile .feature (Gherkin) dosyalarınızı kullanmamızı sağlar.

4. npm install --save-dev @bahmutov/cypress-esbuild-preprocessor
   - Cucumber dosyalarını derlemek için kullanılır.

5. npm install --save-dev esbuild
   - JavaScript, TypeScript ve .feature gibi dosyalarının çalışmasını sağlar.


6. npx cypress open
